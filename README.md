# Aakanksha ❤️

A premium, responsive, and interactive romantic website for Aakanksha.

## ✨ Features
- **Cinematic Landing Page:** Ambient particles, typewriter reveal, and sound-ready entrance.
- **The Aakanksha Edition:** Magazine-style profile section with playful character tags.
- **Polaroid Photo Gallery:** 3D tilt, scattered layouts, and full-screen lightbox with mobile touch swipe.
- **Interactive Story Timeline:** Key moments connected with glowing pathways.
- **15 Things I Love About You:** 3D interactive flip cards.
- **Ho Kaun Tum?:** Emotional typography with slow zoom backdrop and lyrics.
- **4 Months Scrapbook:** Layered polaroid cards with sticky-note stories.
- **Breaking News 📰:** Interactive newspaper clippings with a scrolling live ticker.
- **Sincere Apology & Handwritten Letter:** Minimal, respectful, line-by-line reveal and typewriter cursive stationery.
- **Little Surprise & Final Screen:** Confetti explosions, playful interactions, and replay functionality.
- **Music Player:** Persistent floating audio player with volume & mute controls.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Installation & Run
```bash
npm install
npm run dev
```

Visit `http://localhost:5173` in your browser.

## 📸 Adding Photos & Music
All content, photos, and music paths are configured in:
`src/config/content.js`

Drop photos in:
- `public/photos/` (hero, profile, ho_kaun_tum, final)
- `public/photos/gallery/` (1.jpg to 12.jpg)
- `public/photos/memories/` (1.jpg to 6.jpg)
- `public/photos/timeline/` (1.jpg to 5.jpg)
- `public/music/` (song.mp3)
