# Aakanksha Website

This folder holds the public assets for the website.

## Photos
Place your photos in the following structure:

```
public/
  photos/
    hero.jpg          ← Hero section background
    profile.jpg       ← Her main profile photo (HerSection)
    ho_kaun_tum.jpg   ← Full-screen background for HoKaunTum section
    final.jpg         ← Final page full-screen background
    gallery/
      1.jpg through 12.jpg  ← Gallery photos
    memories/
      1.jpg through 6.jpg   ← 4-months scrapbook photos
    timeline/
      1.jpg through 5.jpg   ← Timeline memory photos
  music/
    song.mp3          ← Your chosen song (update path in content.js)
```

All images gracefully show a pink gradient placeholder if the file is missing — 
so the website works even before you add photos.
